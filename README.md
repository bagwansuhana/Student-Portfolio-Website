# Student Portfolio Website

A responsive personal portfolio made with HTML, CSS, and vanilla JavaScript.

## Features
- Mobile-friendly navigation
- About, projects, skills, and contact sections
- Contact form validation and status message
- Current year updates automatically
- No frameworks or build tools required

## Run
Open `index.html` in a modern browser.

## Customize
Replace `Your Name`, update project cards and skills, and edit colors in `style.css`.

## Note
The contact form is a front-end demo; it does not send or store messages.
